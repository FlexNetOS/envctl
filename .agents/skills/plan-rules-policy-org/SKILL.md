# plan-rules-policy-org — rules, policy, agent org chart, A2A axis

Planning is incomplete unless it captures how work is governed and which agents own it. Emit
`.handoff/loop/plan/findings/rules-policy-org-<T>.md`.

Required sections:
1. **Policy table** — Upgrade Only, No Downgrades, strict parity before removal, automate everything
   researchable, human only at explicit supervised/risk boundaries, no silent model/provider downgrade.
2. **Agent org chart** — commander/orchestrator, background lanes, specialists, verifier, architect,
   continuity, evolution, and escalation paths.
3. **A2A/weave communication map** — who sends/receives, inbox scan cadence, background-agent status
   ledger, missed-message prevention, and foreground-chat non-blocking rule.
4. **Replacement-of-human-bottleneck plan** — each manual action categorized as automate now,
   supervised, or owner-only with evidence.
5. **Upgrade rows** — `axis: rules-policy-org`, evidence, acceptance, risk, reversibility.
