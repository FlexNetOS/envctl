## Dimension verdict (1–3 lines)

rusty-idd is a **clean-DAG, engine-first pure-Rust control plane** (OpenSpec model at its center) whose
*architecture is sound but whose mass is mis-distributed*: three god-files concentrate the risk
(runner.rs blast 803, tui/app.rs 195 KB, knowledge/lib.rs 247 KB single file), ~182 of ~278 dead
symbols sit in vendored `codegraph-*` trees that triple-duplicate handoff/prompt_hub, and the one seam
shaped for the fabric (`work-order` = handoff.task.v1) is wired-but-unconsumed. The convergence path
into weave/icm/grit/hf exists only as **filesystem+schema contracts and a descriptive repo-catalog**,
never as library/IPC bindings — that absence is the plannable gap.

## Named gaps (what the dimension reveals)

- **G1 — Risk concentrated in god-files.** Three files (runner.rs blast 803, app.rs 195 KB/blast 248, knowledge/lib.rs 247 KB/blast 105) hold the product's highest blast radius AND its largest line-counts simultaneously — any change there is high-risk and hard to test in isolation. This is the dominant code-quality + maintainability gap. (vs trends C1: best-practice is workspace-of-specialized-crates / modular split — the `spec` crate already models this; the big three do not.)
- **G2 — Vendored bloat + triple-duplication.** 182 dead symbols and the widest public surface live in vendored `codegraph-*`; handoff is vendored 3× (`third_party/upstream/handoff`, `imports/handoff`) plus prompt_hub/prompts.chat/codegraph-rust. Inflates build, index, and audit surface; keeps deprecated `serde_yaml` in the lock. (graph F1/F2)
- **G3 — The fabric seam is un-integrated.** `work-order` is shaped to `handoff.task.v1` but consumed by nothing; the convergence into weave/icm/grit/hf is filesystem-contract-only. The path *into* the one fabric is undesigned in product code — the headline architectural gap. (codemap Convergence; trends D1 A2A v1.0 is the external interop target).
- **G4 — Control-plane completeness.** The OpenSpec engine (`spec`) has modules (merge.rs 21 KB, scaffold, schema) whose API is partially unwired to the CLI (30 dead) — the spec lifecycle's full surface is not all reachable from the front door.
- **G5 — Stray/ambiguous repo layout.** `crates/config/` is a non-crate orphan; mixed editions; `[patch.crates-io]` override for repomix-shared — small governance/config-drift items that erode the otherwise-clean layout.
